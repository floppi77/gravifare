# Sicherheit · Security

**Deutsch:** Sicherheitskorrekturen gibt es nur für das jeweils neueste Release. Bitte keine öffentlichen Issues für Sicherheitsprobleme,
sondern auf GitHub unter **Security › Report a vulnerability** eine private Meldung anlegen. Die Release-Pakete sind nicht signiert; Prüfsummen stehen in `SHA256SUMS.txt`.

**English:** Only the latest release receives security fixes. Please do not open public issues for security problems; use
**Security › Report a vulnerability** on GitHub instead. Release packages are unsigned; checksums are in `SHA256SUMS.txt`.
